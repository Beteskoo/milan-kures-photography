# Milan Kureš | Bird & Nature Photographer

Pracovní náhled fotografického webu Milana Kureše.

Obsahuje:

- responzivní úvodní stránku,
- samostatnou stránku O mně,
- samostatnou galerii s osmi kolekcemi podle lokality,
- šestnáct reprezentativních fotografií v lokalitních kolekcích,
- českou, německou a anglickou jazykovou variantu,
- filtrování lokalit, prohlížení fotografií v detailu a mobilní navigaci,
- datové identifikátory připravené pro budoucí detail fotografie a případný e-shop.

Tento repozitář slouží pouze jako veřejný náhled rozpracovaného webu.
